# CHINT ETM MDM

CHINT ETM MDM готовит данные о товарах CHINT для партнёров из локальной базы:

- карточки товаров для ЭТМ (`upload_goods`): сама подбирает класс ЭТМ,
  заполняет шаблон класса и показывает, что проверить и дозаполнить;
- архивы РАЭК: заполняет пустые клетки, сертификаты, ссылки и картинки;
- запросы продактам: чего нет в базе, уходит продактам в Excel, ответы
  проверяются и подставляются сами — и для РАЭК, и для ЭТМ;
- база: обновление из прайса и ETIM-файлов, ручные дозаполнения, бэкапы и откат.

Программа рассчитана на обычную работу без Python, терминала и прав
администратора.

## Установка (Windows и Linux)

1. Откройте страницу выпусков:
   https://github.com/markiitwo/chint_etm_mdm/releases/latest
2. Скачайте файл для своей системы:
   - Windows: `CHINT_ETM_MDM_portable.zip`;
   - Linux: `CHINT_ETM_MDM_portable_linux.tar.gz`.
3. Распакуйте архив куда угодно и запустите `CHINT ETM MDM` из папки.
4. Программа спросит «Установить программу на этот компьютер?». Нажмите «Да».
   На рабочем столе и в меню появится значок. Распакованную папку после этого
   можно удалить.

Базы, шаблоны и настройки хранятся отдельно от программы, поэтому установка,
обновление и откат их не трогают.

## Обновления

При запуске установленная программа проверяет, вышла ли новая версия, и
спрашивает «Обновить сейчас?». После обновления она перезапускается сама.
Предыдущая версия сохраняется: если новая работает плохо, выберите в меню
«Программа» пункт «Вернуть предыдущую версию». Там же есть «Проверить
обновления».

Новая версия выходит, когда в `src/chint_etm_mdm/__init__.py` поднят номер
версии и изменение принято в `main`: GitHub сам проверяет программу, собирает
версии для Windows и Linux и публикует выпуск. Правки без нового номера версии
до пользователя не доходят. Что нового в каждой версии — в
[CHANGELOG.md](CHANGELOG.md): раздел версии попадает в описание выпуска.

Старая установка на Linux через `install_linux.sh` при следующем запуске
значка сама переходит на готовую версию и заменяет значок.

## Первый запуск

1. Установите программу (раздел «Установка» выше).
2. На вкладке `База` проверьте рабочую папку и базу `chint_mdm.sqlite`.
   Программа сама ищет базу в рабочей папке, «Загрузках» и «Документах».
3. Если файлы от коллег приходят в общую папку, укажите её как «Папку
   входящих».
4. Дальше — вкладка `ЭТМ` (карточки товаров) или `РАЭК`.

Если Windows покажет предупреждение о неизвестном издателе, нажмите
`Подробнее` -> `Выполнить в любом случае`. Это обычное предупреждение для
внутренних программ без цифровой подписи.

## Карточки товаров для ЭТМ

Всё для ЭТМ — на вкладке `ЭТМ`.

1. Обновите базу из свежего прайса (вкладка `Обновление базы`).
2. На вкладке `ЭТМ` выберите, для каких товаров делать карточки:
   - `Новинки, появившиеся после` — дата сама ставится на день прошлого
     запуска;
   - `Эти артикулы` — впишите или вставьте артикулы (через пробел, запятую или
     с новой строки).
3. Нажмите `Сделать карточки`.

Программа подберёт каждому товару класс ЭТМ («81 класс»), заполнит шаблон
этого класса и сложит всё в одну папку `ЭТМ карточки <дата время>` в `output`
рабочей папки. Сама откроется `Итог.xlsx`:

- `Что делать` — шаги по порядку, только те, что нужны;
- `Товары` — каждый товар, его класс, состояние (готово к загрузке, проверить,
  сколько пустых полей, нет шаблона) и в каком файле он лежит;
- `Дозаполнить` — все пустые поля всех карточек одним списком, с допустимыми
  значениями из списка ЭТМ;
- `Проверить` — значения, подобранные по похожему, диапазоны, противоречия с
  названием и неуверенно подобранные классы, с причиной;
- `Нет шаблона` — классы, шаблон которых нужно скачать.

В папке три подпапки:

- `Загрузить в ЭТМ` — файлы, которые можно грузить сразу (один файл — один
  класс ЭТМ, по-другому ЭТМ не принимает);
- `На проверку` — карточки, которые стоит посмотреть перед загрузкой;
- `Служебное` — рабочие копии и подробные отчёты, обычно туда смотреть не нужно.

Шаблоны классов скачиваются в личном кабинете ЭТМ
(`upload_goods_category_template_<класс>.xlsx`). Сохраните их в «Загрузки» или
папку входящих: при следующем нажатии программа сама заберёт их в папку
шаблонов. Файл ЧЗ с кодами ТН ВЭД и ОКПД2 программа тоже берёт сама —
самый свежий по дате в названии.

### Запросы продактам для ЭТМ

Пустые поля можно спросить у продактов, как для РАЭК: кнопка
`Запросить у продактов` на вкладке `ЭТМ`. Каждому продакту — Excel с жёлтой
колонкой «Ответ» и черновик письма. Где у ЭТМ закрытый список, в ответе
выпадающий список значений ЭТМ: из шаблона класса, а если там списка нет — из
справочника характеристик ЭТМ (вкладка «Правила маппинга»). Для числовых
характеристик справочника подсказка «число». Так ответ сразу приходит в формате
ЭТМ.

Ответы принимаются кнопкой `Принять ответы продактов...` с теми же
проверками, что и для РАЭК. После этого программа предложит собрать карточки
тех же товаров заново, уже с ответами (то же делает кнопка `Ещё раз для тех же
товаров`; она же нужна, когда вы докачали шаблоны классов: дата новинок после
запуска уже сдвинулась на сегодня). Запросить у продактов можно и после
перезапуска программы — для последнего запуска.

Ответы продактов, присланные для РАЭК, используются и в карточках ЭТМ:

- штрих-коды, коды ТН ВЭД и ОКПД2 подставляются как есть;
- характеристики («С блоком управления = Да») считаются данными товара: если
  у ЭТМ поле называется так же или вы уже подтверждали эту пару названий (лист
  «Названия» в отчёте), значение подбирается к списку ЭТМ, похожее — с отметкой
  «Проверить». Что не сошлось, программа спросит у продактов уже со списком ЭТМ.

Подтвердите пары названий на листе «Названия» отчёта из папки `Служебное` и
импортируйте отчёт кнопкой `Импортировать ручные значения`: в следующий раз
такие ответы лягут в ЭТМ сами.

После запуска сам открывается `Итог.xlsx`, а в окне — коротко цифры: сколько
можно загружать сразу, сколько посмотреть, сколько пустых полей. Имена файлов
на листе `Товары` — ссылки: по клику файл открывается.

### Материалы для карточек: фото, документы, сертификаты, описания

После создания карточек ЭТМ принимает остальное отдельными формами. Кнопка
`Сделать материалы` на вкладке `ЭТМ` готовит все четыре для товаров последних
карточек (или для вписанных артикулов) в папку `ЭТМ материалы <дата время>`:

- фото — главное фото товара с ensmas.ru: имя файла и прямая ссылка на него, ЭТМ
  заберёт его сам (имя файла может быть любым, хоть кириллицей). Берутся только фото из каталога сайта; если у товара своего
  фото нет, сайт подставляет логотип — такой товар уходит в «Проверить», а не в
  форму (и в РАЭК так же остаётся «Нет картинки»);
- техническая информация — документы со страницы товара на ensmas.ru (паспорт,
  руководство, каталог, чертежи `.dwg`, модели `.stp`); тип для ЭТМ программа
  определяет по имени файла, сами файлы скачивает в `Файлы для загрузки`;
- сертификаты — номер и ссылка на реестр из файла ЧЗ, даты из
  `Сертификаты.xlsx` (вкладка РАЭК), код типа (ДТРЕАЭС, СТРЕАЭС…) и код
  аккредитации из номера, PDF с сайта в `Файлы для загрузки`; если у документа
  нет даты окончания — плюс 10 лет, как требует ЭТМ. Номера вроде «24/11/0005» или
  «29.05.2026-15ССП» в файле ЧЗ — отказные письма (товару сертификат не нужен):
  они идут с типом ПОТКАЗ, без ссылки на реестр; дата берётся из номера, если она
  там есть, иначе из `Сертификаты.xlsx`. Таблица общая с РАЭК; кнопки
  `Таблица сертификатов` и `Взять даты из файла...` есть и в блоке материалов
  на вкладке `ЭТМ`;
- описания — одно на серию, из таблицы `Описания серий.xlsx` в рабочей папке.
  Кнопка `Описания серий` открывает её (новые серии добавляются пустыми строками),
  кнопка `Взять описания из файла ЭТМ...` переносит тексты из файла описаний,
  который уже загружали в ЭТМ. Программа приводит текст к правилам ЭТМ (одна
  строка, без «;», «°», кавычек), а описание не той длины (нужно 250–1000
  символов) кладёт в `На проверку`.

Кнопка `Разобрать отчёт ЭТМ...` берёт отчёты из личного кабинета ЭТМ и делает
материалы только для того, чего в карточках не хватает:

- список товаров (`goodsList_...xlsx`, колонки «Наличие Фото», «Наличие
  описания», «Наличие файлов тех.информации», «Наличие 2D/3D модели»…): фото,
  описание и документы только тем товарам, у которых их нет; товары с
  «Поставляемый: Нет» не трогаются; 2D/3D — по вашему выбору (их обычно тысячи,
  а сайт спрашивается по 2–3 секунды на товар, ответы запоминаются);
- отчёт по сертификатам (`report_sert_...csv`, колонка «Причина»): строки
  сертификатов этих товаров заново из файла ЧЗ — с ссылкой на реестр и
  правильными кодами;
- карточки без ТН ВЭД или ОКПД2 перечислены на листе `Коды в карточке` в
  `Итог.xlsx`, с кодами из файла ЧЗ, если они там есть.

Можно выбрать оба отчёта сразу.

Готовые формы лежат в `Загрузить в ЭТМ`, каждая — в свою форму личного кабинета;
к «Тех. информации» и «Сертификатам» приложите файлы из `Файлы для загрузки`.
Чего не нашлось (нет фото на сайте, нет дат сертификата, нет описания серии),
перечислено на листе `Проверить` в `Итог.xlsx`. Скачанные файлы запоминаются в
рабочей папке и второй раз не скачиваются.

### Свой шаблон upload_goods

Если класс нужно выбрать вручную или есть свой файл `upload_goods`, внизу
вкладки `ЭТМ` есть блок `Свой шаблон upload_goods`: выберите файл и нажмите
`Заполнить из базы` (подробнее — раздел «Заполнение своего шаблона» ниже).

## РАЭК

1. Сохраните архив от менеджера РАЭК в папку входящих или «Загрузки». Туда же
   кладите свежий файл ЧЗ: из него берутся ТН ВЭД, ОКПД2, штрих-коды и ссылки
   на реестр ФСА.
2. На вкладке `РАЭК` нажмите `Заполнить архив РАЭК`. Программа сама возьмёт
   самый свежий архив РАЭК.
3. В папке `output/раэк_<дата>` появятся `<архив>_заполнено_<дата>.zip`
   (его и отправляете менеджеру) и отчёт. В отчёте: что стоит проверить, чего
   нет в базе и почему, и лист «Названия» — какие характеристики программа
   сопоставила по похожему названию.
4. Напишите «да» или «нет» в последней колонке листа «Названия», сохраните
   отчёт и нажмите `Запомнить ответы из отчёта...`. В следующий раз программа
   учтёт это сама.

Уже заполненные РАЭК клетки программа не трогает. Значения пишет так, как в
последних файлах РАЭК: текстом, с десятичной запятой, диапазоны как
`24...24`, да/нет как `true`/`false`, значения из списков в написании РАЭК.
Постоянные значения (страна) и проверенные пары характеристик лежат в
`src/chint_etm_mdm/partners/raek.json`.

«Подлежит обязательному подтверждению соответствия» программа берёт из файла
ЧЗ, колонка «Сертификат 1»: сертификат или декларация ЕАЭС — «Да»,
«не требуется» — «Нет». Отказное письмо вместо сертификата даёт «Нет» с
пометкой на проверку. Если артикула в файле ЧЗ нет или сертификат не указан,
клетка остаётся пустой, причина пишется в отчёт.

### Сайт ensmas.ru

С галочкой «Сначала взять ссылки, картинки и сертификаты с сайта» программа
перед заполнением ищет каждый товар на ensmas.ru по артикулу (проверяет, что
артикул на странице тот же) и берёт ссылку на страницу товара, главную
картинку и номер сертификата. Ответы сайта хранятся в рабочей папке
(`cache/ensmas_site.json`) и обновляются раз в месяц, поэтому второй запуск
идёт без интернета и быстро. Сертификат с сайта используется, только если в
файле ЧЗ по артикулу ничего нет, и всегда помечается на проверку.

### Таблица сертификатов

Даты сертификатов вписываются один раз на документ, а не на каждый товар.
Кнопка `Таблица сертификатов` создаёт в рабочей папке `Сертификаты.xlsx`: по
строке на каждый сертификат и декларацию ЕАЭС и на каждое отказное письмо из
файла ЧЗ, с числом товаров и сериями. Даты, которые уже есть в базе, подставлены; пустые клетки жёлтые —
впишите даты и сохраните. Программа ставит их всем товарам с этим документом.
Новые документы добавляются при следующем нажатии, вписанные даты не
трогаются. Истекшие и истекающие в ближайшие 90 дней подсвечиваются. Если в
файле ЧЗ появятся колонки с датами (например «Сертификат 1 от» и
«Сертификат 1 до»), программа возьмёт даты оттуда сама.

Если даты уже вписаны раньше в другом файле (например, в форме партнёра, где
на каждый товар есть «Номер сертификата», «Начало действия сертификата» и
«Окончание действия сертификата»), нажмите `Взять даты из файла...` и выберите
его. Программа перенесёт даты в таблицу. Даты, вписанные в таблицу вручную,
не меняются.

### Запросы продактам

Чего нет в базе, можно спросить у продактов. После заполнения архива нажмите
`Запросить у продактов`. По файлу «Закрепление ПМ.xlsx» (в папке входящих,
«Загрузках» или рабочей папке) программа решает по серии товара, кому писать, и делает каждому
продакту Excel-файл с жёлтой колонкой «Ответ» (где у РАЭК закрытый список — с
выпадающим списком) и черновик письма `.eml` с этим файлом. Почты продактов
вписываются один раз в `Почты продактов.xlsx` в рабочей папке.

Продакт присылает файл обратно — нажмите `Принять ответы продактов...` и
выберите его. Программа проверяет каждый ответ (числа, коды, значения из списка
РАЭК) и сразу использует хорошие при следующем заполнении. Что не прошло
проверку, показывается в журнале. Уже заданные вопросы, на которые ещё нет
ответа, повторно не задаются 30 дней. Если нужно сделать файлы запросов заново (прежние
потерялись, были с ошибкой или вы только что вписали почты), нажмите
`Запросить у продактов` ещё раз и согласитесь на вопрос «Сделать файлы запросов
заново?». Ответы на прежние файлы программа всё равно примет.

## Рабочая папка

Рабочая папка - это место, где программа хранит базу, отчеты, скачанные прайсы
и пользовательские правила. Лучше выбрать отдельную папку, например:

```text
Документы\CHINT ETM MDM Work
```

Внутри нее программа использует такие подпапки:

```text
database\               база данных
output\                 результаты: «ЭТМ карточки <дата время>», «раэк_<дата>»,
                        «запросы_продактам_<дата>», заполненные свои шаблоны
reports\                отчёты импортов ETIM и проверки размеров
downloads\price\        скачанные прайс-листы
etm_class_templates\    шаблоны классов ЭТМ
rules\                  правила маппинга, ручные дозаполнения, ответы продактов
cache\                  ответы сайта ensmas.ru
input\                  сюда тоже можно класть файл ЧЗ
```

Там же лежат `Почты продактов.xlsx` и `Сертификаты.xlsx`.

### Сводка на почту и в Telegram

Кнопка `Сводка на почту и в Telegram...` на вкладке `База` открывает настройки.
С галочкой «Отправлять сводку после заполнения» программа после заполнения РАЭК
и карточек ЭТМ отправляет те же строки, что пишет в журнал.

- Почта: адрес получателя, почтовый сервер (например `smtp.yandex.ru`, порт
  465), почта отправителя и пароль приложения из настроек этой почты.
- Telegram: создайте бота у @BotFather, вставьте его токен, напишите боту любое
  сообщение и нажмите `Найти чат`.

Кнопка `Отправить пробную сводку` проверяет настройки. Пароль и токен хранятся
только в профиле пользователя (`~/.config/chint_etm_mdm/notify.json`), не в
рабочей папке.

### Папка входящих

На вкладке `База` можно указать «Папку входящих» — куда приходят файлы от
коллег и партнёров: файл ЧЗ, архивы РАЭК, «Закрепление ПМ.xlsx», ответы
продактов. Сейчас это общая папка RDP, позже — сетевая папка компании.
Программа ищет свежие файлы сначала там, потом в «Загрузках». Готовые файлы
по-прежнему сохраняются в рабочую папку.

## Заполнение своего шаблона

1. На вкладке `База` проверьте рабочую папку и путь к базе.
2. На вкладке `ЭТМ` в блоке `Свой шаблон upload_goods` выберите исходный шаблон.
3. Проверьте папку результата. Обычно это `output` внутри рабочей папки.
4. Нажмите `Заполнить из базы`.
5. Откройте созданный файл `_filled.xlsx`.

Что важно:

- заполненные значения берутся из базы;
- выпадающие списки из исходного шаблона сохраняются;
- обязательные незаполненные ячейки подсвечиваются красным (меняется только
  цвет, шрифт шаблона остаётся); у товара, которого нет в базе, красными
  становятся только пустые ячейки, а ручные значения для него подставляются;
- уже заполненные ячейки не перезаписываются;
- `.xlsm` сохраняется как `.xlsm`, макросы не удаляются;
- рядом создается технический отчет по заполнению.

## Правила маппинга

Некоторые поля в шаблонах ETM называются не так, как характеристики в базе.
Для этого есть правила маппинга.

Если после заполнения остались поля `Конфиг:*` или похожие незаполненные
характеристики:

1. Нажмите `Проанализировать маппинг`.
2. Перейдите на вкладку `Правила маппинга`.
3. Посмотрите предложенные источники и примеры значений.
4. Нажмите `Принять` только у тех строк, где источник точно подходит по смыслу.
5. Нажмите `Отклонить` у неподходящих вариантов.
6. Снова запустите `Заполнить из базы` (для карточек ЭТМ — `Ещё раз для тех же
   товаров`).

Принятые и отклоненные правила сохраняются в рабочей папке и используются в
следующих заполнениях.

Если отклонить источник, который раньше был принят, он перестаёт применяться
(другие принятые источники того же поля остаются). Если потом снова его
принять, он вернётся. Пока идёт заполнение или другая операция, правила
менять нельзя: программа попросит дождаться её окончания. Правки файла правил
вручную подхватываются при следующем заполнении.

## Ручные дозаполнения

Если файл `_filled.xlsx` дозаполнили вручную, эти значения можно сохранить,
чтобы программа подставляла их сама в следующий раз.

1. Заполните шаблон через программу.
2. Дозаполните красные поля вручную в полученном `_filled.xlsx`.
3. В блоке `Ручные дозаполнения` выберите этот дозаполненный файл.
4. Нажмите `Импортировать ручные значения`.
5. Проверьте отчет импорта.

Программа сохраняет только те значения, которые отличаются от данных в базе.
При следующем заполнении они применяются поверх базы. Повторный импорт того же
файла ничего не меняет.

Чтобы снять ранее сохранённое ручное значение, впишите в ячейку значение из
базы и импортируйте файл: ручное значение удалится, и дальше будет браться
значение из базы. Пустая ячейка ручное значение не удаляет.

Для своего шаблона рабочим файлом ручного заполнения является сам
`_filled.xlsx` с красными ячейками. Для карточек ЭТМ и РАЭК пустые поля удобнее
спросить у продактов (разделы «Запросы продактам»).

Файл ручных значений хранится здесь:

```text
<рабочая папка>\rules\manual_values.json
```

## Обновление прайса

На вкладке `Обновление базы` можно обновить базу из прайс-листа CHINT.

Обычный сценарий:

1. Нажмите `Найти свежий прайс`.
2. Нажмите `Скачать и импортировать`.
3. Дождитесь сообщения об окончании импорта.
4. Проверьте статистику в журнале.

Если прайс уже скачан:

1. Выберите файл `Price-list-CHINT_*.xlsx`.
2. Нажмите `Импортировать выбранный XLSX`.

Перед изменением базы программа создает согласованный SQLite-бэкап рядом с
файлом базы.

`Найти свежий прайс` берёт с сайта ссылку на файл `Price-list-CHINT…xlsx`:
сначала низковольтное оборудование, потом самый свежий по дате в названии. Если
сайт не открывается или ссылки на странице нет, программа так и скажет —
тогда скачайте прайс в браузере и нажмите `Импортировать выбранный XLSX`.

Тот же самый файл прайса второй раз не импортируется: программа сообщит, что
он уже был импортирован, и базу не тронет. При импорте из файла она спросит,
нужен ли повторный импорт: он нужен только если базу откатывали из бэкапа.
Для этого программа запоминает отпечаток файла в базе: при первом импорте
прайса новой версией в таблицу снимков добавится одна пустая колонка, прежние
версии программы с базой работают как раньше.

Копия файла с `_1` или ` (1)` в имени получает ту же дату снимка, что и
оригинал. Одинаковые строки одного артикула в прайсе записываются один раз; если
у артикула в прайсе разные строки, программа берёт последнюю и перечисляет такие
артикулы в итогах. Цены `100` и `100,00` считаются одинаковыми.

## Импорт ETIM

ETIM-файл нужен для загрузки характеристик и габаритов.

1. На вкладке `Обновление базы` выберите ETIM-файл `.xlsx` или `.xlsm`.
   Файл в старом формате Excel (`.xls`, в том числе переименованный в `.xlsx`)
   программа сама пересохранит через LibreOffice, если он установлен. Файл с
   паролем или меткой конфиденциальности прочитать нельзя: программа скажет об
   этом до бэкапа базы, снимите защиту и сохраните книгу заново.
2. Нажмите `Импортировать ETIM`.
3. Дождитесь завершения импорта.
4. Откройте созданный отчет кнопкой `Открыть отчет ETIM`.

Программа ищет артикулы из базы во всех листах ETIM-файла, записывает найденные
характеристики и дозаполняет пустые габариты. Если товар есть на нескольких
листах (например, кратко на одном и подробно на другом), данные собираются со
всех. Колонки вроде «Артикул аналога» или «Заменяет артикул» не считаются
артикулом самого товара.

Габаритами товара считаются только колонки, где кроме слова «Длина», «Ширина»,
«Высота» или «Глубина» и единицы есть разве что «габаритная», «корпуса»,
«изделия» и подобные слова. «Макс. длина кабеля», «Ширина шины», «Длина
упаковки» и т.п. остаются обычными характеристиками. Размер больше 10 м
программа тоже не берёт.

В отчёте есть ещё два листа:

- `Разное в файле` - у одного товара в самом ETIM-файле разные значения одного
  поля. Разные габариты в базу не записываются, их нужно проверить; для прочих
  характеристик записано первое значение.
- `Нет в базе` - артикулы из файла, которых нет в базе.

Если в файле не нашлось ни одного артикула из базы, программа прямо об этом
предупредит. Сначала программа читает файл и готовит отчёт, и только потом
записывает в базу: если файл не читается или отчёт не удаётся сохранить
(например, нет места на диске), база не меняется.

Уже заполненные габариты не перезаписываются автоматически. Если в базе уже
есть значение, а из ETIM пришло другое, строка попадает в отчет `Конфликты`.

## Разбор конфликтов ETIM

Откройте отчет ETIM и перейдите на лист `Конфликты`.

В первой колонке `Решение` выберите один из вариантов:

- `Оставить базу` - ничего не менять;
- `Принять ETIM` - записать значение из ETIM в базу.

После заполнения решений:

1. Сохраните Excel-файл отчета.
2. Вернитесь в программу.
3. Нажмите `Применить решения ETIM`.

Программа применит только строки, где явно выбрано `Принять ETIM`. Перед этим
она создаст новый согласованный бэкап базы.

## Проверка размеров, уже записанных в базу

До версии 0.5.7 импорт ETIM мог взять за длину, ширину или высоту товара
другую колонку, например «Макс. длина кабеля, м» (1000 м превращались в длину
1 000 000 мм). Чтобы найти такие значения в базе:

1. На вкладке `База` нажмите `Проверить размеры в базе`.
2. Программа только читает базу и открывает отчёт `dimension_check_...xlsx`
   (лист `Проверить`): артикул, поле, значение, в чём проблема и из какой
   колонки ETIM оно пришло.
3. Значения, пришедшие из ETIM не из той колонки (и размеры больше 10 м из
   ETIM), программа предложит очистить. Перед очисткой делается бэкап базы.
   Остальные строки отчёта (размер меньше 1 мм, порядок «100x200x300» без
   подписи, размеры больше 10 м не из ETIM) только показываются: проверьте их
   сами.
4. После очистки импортируйте ETIM-файл ещё раз: пустые размеры заполнятся из
   правильных колонок.

Решения из старых отчётов ETIM со значением из неподходящей колонки программа
больше не применяет, даже если выбрано `Принять ETIM`.

## Копирование базы в рабочую папку

Кнопка `Копировать базу в рабочую папку` на вкладке `База` копирует выбранную
базу в `database\chint_mdm.sqlite` рабочей папки, в фоне. Если там уже есть
база, программа спросит, заменить ли её, и сначала сохранит старую рядом
бэкапом. Если выбран файл, который не является базой программы, она скажет об
этом сразу, до любой операции.

## Откат базы из бэкапа

Если после импорта что-то пошло не так:

1. На вкладке `База` выберите текущую базу.
2. В поле бэкапа выберите нужный файл `.bak_*`.
3. Нажмите `Откатить базу из бэкапа`.

Перед откатом программа сохраняет текущую базу в отдельный согласованный
бэкап `.before_restore_*`, чтобы можно было вернуться назад.

Откат идёт в фоне, окно при этом не зависает. Программа откажется
откатывать и не тронет базу, если выбран сам файл базы, файл повреждён,
это не база SQLite или база другой программы (в ней нет таблиц товаров и
прайса).

## Закрытие программы во время работы

Пока идёт операция (импорт, заполнение, откат и т.п.), другую запустить
нельзя. Если в это время закрыть окно, программа спросит, закрыться ли ей
самой, когда операция закончится. Так база и файлы не останутся записанными
наполовину.

## Если программа не запускается

Проверьте по порядку:

- при первом запуске архив полностью распакован, программа не запускается
  прямо из zip;
- путь к папке не слишком длинный;
- папка доступна на запись;
- антивирус не поместил `.exe` или соседние файлы в карантин;
- база не открыта другой программой в режиме блокировки.

Если ошибка повторяется, передайте текст ошибки и опишите, на каком действии
она появилась.

## Сборка portable-версии

Обычно собирать вручную не нужно: GitHub собирает обе версии сам при каждом
изменении. Этот раздел нужен, только если сборку надо сделать на своём
компьютере.

Для сборки нужен установленный Python 3.10 или новее. Права администратора не
требуются: скрипт создает локальную `.venv` внутри папки проекта.

На Windows запустите:

```bat
build_windows.bat
```

Скрипт:

- перейдет в папку проекта;
- создаст `.venv`, если ее еще нет;
- установит зависимости и PyInstaller;
- соберет приложение в `dist\CHINT ETM MDM`;
- создаст архив `dist\CHINT_ETM_MDM_portable.zip`.

Пользователям нужно передавать именно архив `CHINT_ETM_MDM_portable.zip`.
Python, `.venv`, исходники проекта и права администратора им не нужны.

На Linux запустите:

```bash
./build_linux.sh
```

Скрипт делает то же самое и собирает приложение в `dist/CHINT ETM MDM`, а
архив — в `dist/CHINT_ETM_MDM_portable_linux.tar.gz`. Пользователю достаточно
распаковать архив и запустить файл `CHINT ETM MDM` внутри папки.

## Шаблоны партнёров

Данные товара хранятся в базе отдельно от формата конкретного партнёра. Как
заполнять файл партнёра, описано в отдельном файле-шаблоне
`src/chint_etm_mdm/partners/<код>.json`. Сейчас есть шаблон ЭТМ (`etm.json`).

В шаблоне для каждой колонки указано, какое поле товара в нее идет, как его
оформить (перевести мм в метры, округлить, обрезать длину) и какую подсказку
показать в отчете, если значения нет. Колонки с префиксом `Конфиг:` берутся из
характеристик товара и правил маппинга.

### Характеристики ЭТМ и справочник допустимых значений

1. На вкладке «Правила маппинга» нажмите «Загрузить справочник характеристик
   ЭТМ...» и выберите файл «Справочник» из iPRO OneTeam. Его стоит обновлять,
   когда ЭТМ присылает новый.
2. Отчет ЭТМ «Товары недостающие характеристики» (CSV `rxreport_...`)
   заполняется в блоке `Свой шаблон upload_goods` на вкладке `ЭТМ`: выберите
   его как шаблон и нажмите `Заполнить из базы`.
   Программа заполнит только колонку значений, остальное в файле не меняется.
   Заполненные строки она делит на два файла: `upload_char_..._<дата>.csv`
   можно грузить сразу, `..._check.csv` — после проверки (похожие значения,
   диапазоны, противоречия с названием). Незаполненные строки остаются только
   в отчёте.
3. Значения из базы подбираются к допустимым значениям ЭТМ. Уверенные
   совпадения заполняются сразу. Похожие заполняются с пометкой «нужно
   проверить». Если подходящего значения нет, ячейка остается пустой.
4. В отчете о заполнении есть два листа для проверки:
   - «Сопоставления»: одна строка на каждое значение из базы, которое нужно
     проверить или выбрать. Впишите или поправьте «Принять значение».
   - «Названия»: какая характеристика из базы может соответствовать
     характеристике ЭТМ. Напишите «да» в последней колонке у верных строк.
5. Загрузите этот отчет кнопкой импорта ручных дозаполнений. Программа
   запомнит выбор и в следующий раз заполнит такие значения сама.
   Заполненный вручную отчет ЭТМ тоже можно загрузить: введенные значения
   сохранятся как ручные.

Тест `tests/test_etm_golden.py` сверяет заполнение ЭТМ с сохраненным эталоном.
Если заполнение ЭТМ нужно изменить намеренно, эталон пересоздается командой
`PYTHONPATH=src python3 tests/etm_golden_cases.py`.
